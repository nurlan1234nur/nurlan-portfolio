# Nurlan Portfolio

React 19 + TypeScript + Vite 8 + Tailwind CSS 4 single-page portfolio.

## Commands

- `npm run dev` — local development on port 8443
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build
- `npm run format` — format source files

## Structure

- `src/App.tsx` — bilingual content, project data, and page components
- `src/index.css` — Tailwind import, theme tokens, and global styles
- `src/main.tsx` — React entry point
- `index.html` — metadata and application shell
- `vite.config.ts` — minimal Vite configuration

Keep Mongolian and English copy in sync. Project deployment links can be added to the project objects in `src/App.tsx` when available.
